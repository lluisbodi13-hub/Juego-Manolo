# Archivos para enviar

Cada juego es un único archivo HTML que funciona solo: se descarga, se hace doble clic y se abre en el navegador, sin instalar nada y sin cuenta de Claude.

- `quien-es-quien.html`: Quién es quién · Introducción al sistema financiero internacional.
- `escape-offshore.html`: Escape Offshore · El Euromercado (incluye la librería 3D dentro, funciona sin internet).
